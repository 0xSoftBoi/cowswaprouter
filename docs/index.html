// depositAndSettle() — 4 steps
01

Pull tokens

transferFrom(owner, router, amount) — brings tokens on-chain into the router contract.

02

Approve relayer

approve(cowRelayer, amount) — grants the CoW vault relayer permission to move funds.

03

Deposit

ICowVaultRelayer.deposit(token, owner, amount) — registers funds with CoW's settlement infrastructure.

04

Settle (optional)

ICowSettler.settle(orderUid) — finalizes the batch auction. Pass empty bytes to leave order pending in the queue.

// Why batch auctions?

No price oracle

The batch finds the best price across all submitted orders simultaneously — no single AMM dictates the rate.

Uniform clearing

All matched orders in a batch settle at the same price. There's no advantage to being first in the block.

Solver competition

Off-chain solvers compete to find the optimal settlement. The winner gets the surplus — not a searcher.
